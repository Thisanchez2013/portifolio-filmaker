# Portifólio Filmaker

Criação de site portfólio premium para Filmmaker e Editor de Vídeos

Crie um site de portfólio profissional, moderno, cinematográfico e altamente visual para um Filmmaker e Editor de Vídeos.

O profissional trabalha com:

Captação de vídeos;

Filmagem de eventos e festas;

Produção de conteúdo para empresas e marcas;

Vídeos institucionais;

Conteúdo para redes sociais;

Edição e pós-produção;

Produção de peças publicitárias;

Filmes e projetos audiovisuais;

Conteúdos destinados a Instagram, TikTok, YouTube e outras plataformas.

O objetivo principal do site é apresentar o trabalho desse profissional de maneira impactante e premium, fazendo com que potenciais clientes conheçam seus projetos, entendam seus serviços e entrem em contato para solicitar orçamento.

O PORTFÓLIO E OS VÍDEOS DEVEM SER OS GRANDES PROTAGONISTAS DO SITE.

Referências

Utilize os sites abaixo como principais referências de direção visual, estrutura, apresentação de projetos e experiência:

https://zaakfilms.com/work

https://rolefilmes.com/

https://fixe.com.br/servicos/

Não quero uma cópia desses sites.

Analise os conceitos presentes nessas referências e crie uma identidade própria para o projeto, aproveitando principalmente:

apresentação cinematográfica;

uso de vídeos e imagens grandes;

minimalismo;

tipografia marcante;

organização do portfólio;

apresentação dos serviços;

transições;

microinterações;

sensação de produto premium;

navegação simples;

bastante espaço visual;

foco no trabalho audiovisual.

O resultado deve parecer o site de um filmmaker/diretor criativo premium, e não um template genérico de agência de marketing.

Direção visual

Quero uma estética:

Cinematográfica + Minimalista + Moderna + Premium + Criativa.

Utilize preferencialmente:

Fundo preto ou muito escuro;

Textos brancos/off-white;

Tons de cinza;

Uma cor de destaque utilizada de maneira muito controlada;

Tipografia moderna e impactante;

Títulos grandes;

Bastante espaço entre elementos;

Vídeos e imagens ocupando grandes áreas;

Layout editorial;

Grid moderno;

Bordas e elementos discretos;

Poucos elementos decorativos.

Evite:

excesso de cards;

gradientes genéricos;

excesso de cores;

sombras exageradas;

aparência de template SaaS;

visual corporativo tradicional;

excesso de textos;

ícones desnecessários;

elementos que desviem atenção dos vídeos.

A sensação deve ser semelhante a navegar pelo portfólio de um diretor de cinema, produtora audiovisual ou estúdio criativo.

transição cinematográfica.

Animações

Quero animações sofisticadas e suaves.

Utilizar animações de entrada conforme scroll, como:

fade;

reveal;

translate;

mask reveal;

parallax muito discreto;

stagger em textos.

Títulos grandes podem surgir utilizando efeito de clipping/mask.

Imagens podem ter pequenos movimentos de escala.

Evitar animações exageradas.

O objetivo é criar uma sensação cinematográfica e premium.

Priorizar animações performáticas utilizando transform e opacity.

Respeitar prefers-reduced-motion.

Cursor

No desktop, pode existir um cursor personalizado muito discreto.

Ao passar sobre projetos:

VIEW

Ao passar sobre vídeo:

PLAY

Ao passar sobre links:

pequena alteração visual.

Não utilizar cursor customizado no mobile.

Scroll

Utilizar smooth scrolling de maneira sutil.

Não criar scroll artificial pesado.

A navegação deve continuar rápida e natural.

Responsividade

O site PRECISA funcionar perfeitamente em:

Desktop;

Notebook;

Tablet;

Smartphone.

Mobile não pode simplesmente ser uma versão espremida do desktop.

Adaptar:

tamanhos de títulos;

grids;

vídeos;

menus;

espaçamentos;

interações;

CTAs.

No mobile:

projetos em coluna;

thumbnails grandes;

navegação fullscreen;

evitar efeitos dependentes de hover;

botões com área confortável para toque.

Performance

Como será um portfólio audiovisual, performance é extremamente importante.

Implementar:

lazy loading;

imagens otimizadas;

vídeos carregados de maneira inteligente;

thumbnails antes do carregamento dos vídeos;

poster images;

preload somente quando necessário;

evitar carregar todos os vídeos imediatamente;

componentes bem organizados;

animações performáticas.

Não permitir que o Hero e o portfólio deixem o site extremamente pesado.

Experiência desejada

Quando alguém acessar o site, quero que a sequência de percepção seja:

"Esse profissional tem um trabalho visual muito forte."

"Quero assistir aos projetos."

"Entendi rapidamente o que ele faz."

"Esse profissional parece premium e profissional."

"Quero contratar/falar com ele."

Portanto, priorize:

TRABALHO → IMPACTO VISUAL → CREDIBILIDADE → SERVIÇOS → CONTATO

e não:

TEXTOS → EMPRESA → HISTÓRIA → PORTFÓLIO

O visitante deve conseguir chegar aos melhores trabalhos praticamente imediatamente.
